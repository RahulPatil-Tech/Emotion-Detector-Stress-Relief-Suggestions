<!-- Project Description -->
This application utilizes **AI-powered emotion detection** and **personalized well-being recommendations** to help users manage stress effectively. Users can either:
- Select an **emoji** representing their current mood.
- Use their **webcam** to detect emotions using **DeepFace**.
- Receive AI-generated stress relief suggestions based on their detected emotion.

---

## 🌟 Features
- **DeepFace-based Emotion Detection** 🧠
- **Google Generative AI (Gemini) for Personalized Suggestions** 🤖
- **Emoji-Based Emotion Selection** 😊
- **Webcam Integration for Real-Time Detection** 🎥
- **Streamlit UI for an Interactive Experience** 🚀

## 🚀 Installation & Setup

### 1️⃣ Clone the Repository
```bash
 git clone https://github.com/your-username/emotion-detector.git
 cd emotion-detector
```

### 2️⃣ Install Dependencies
```bash
pip install -r requirements.txt
```

### 3️⃣ Run the Application
```bash
streamlit run app.py
```
